# 브라우저와 원본 문서 탐색 호환

자료 목록 링크는 현재 탭에서 `/content/…`의 학습 문서를 연다. 문서의 링크와 화면 전환은 브라우저의 탐색 기록을 사용한다. 뒤로 가면 기존 목록의 필터, 펼친 분량과 스크롤 위치를 복원한다. 이전에 공유한 `#/read/<ID>` 링크는 해당 문서로 이동하고 쿼리 및 앵커를 보존한다.

배포 사본은 과목·수업별 저장 경로로 학습 기록과 풀이 상태를 분리한다. 테마 키 `od-theme`는 자료 목록과 같은 출처의 학습 문서가 공유한다. 저장된 테마가 없으면 시스템 설정을 따른다.

검증은 Chromium, Firefox, WebKit에서 학습 문서의 링크, 슬라이드 탐색과 새로고침, 정리노트와 문제 풀이 동작을 점검한다.
