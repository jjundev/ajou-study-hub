# 구현 상태

기준일: 2026-10-25. 요구사항은 PRD v1.0으로 확정했다. 로컬 학습 앱과 실제 자료 검증은 완료했고, Cloudflare 설정·업로드와 실계정 인수는 실행하지 않았다. 자료 수집부터 배포 차단 경로까지 로컬 구현·작업별 리뷰를 마쳤다. 전체 브랜치 리뷰의 지적 9개를 반영했고, 독립된 최종 수정 검토에서 모두 해결됐으며 새 문제는 발견되지 않았다.

2026-10-25 사용자 선택으로 로컬 구현 상태를 유지한다. 클라우드 계정 설정·게시·실계정 인수는 보류하며, 사용자가 배포 재개를 요청할 때 진행한다. 현재 브랜치와 작업 디렉터리, 로컬 검증 증거는 보존한다.

## 확인한 결과

- 원본 5과목·53묶음에서 목록 HTML 217개와 연결 HTML 3개를 수집했다.
- Chromium에서 HTML 220개를 모두 열었다. 대표 7개 자료는 Chromium·Firefox·WebKit, 390px·1440px의 42조합에서 실제로 조작했다.
- 문제풀이·해설·수식·이미지·시뮬레이션·슬라이드 이동·저장 충돌·손상 상태·저장 불가 조건을 확인했다.
- 입력 파일 4,796개와 최종 앱 파일 4,803개의 해시 및 Git 추적 상태가 검증 전후 같았다. 원본 파일을 수정하지 않았다.
- 동적 그림 경로 66개를 명시했다. 정적 참조만으로 빠졌던 해설 PNG 42개를 추가 수집했다.
- 단위 테스트 173개, 타입 검사, Chromium·Firefox·WebKit 전체 브라우저 테스트 168개를 통과했다. 모바일 직접 진입·새로고침·뒤로/앞으로 이동과 선택 문서의 새 탭 열기도 포함한다.
- Wrangler 로컬 서버에서 실제 경로·MIME·캐시·404 등 17개 항목을 확인했다. 빈 검증용 앱은 원본 자료 없이 12개 파일, 21,794바이트로 별도 생성한다.
- 연결된 GitHub에서 앱과 원본 5개 레포의 비공개 상태를 읽기 전용으로 확인했다. 원격 설정 변경·push·PR 생성은 하지 않았다.

검증한 최종 앱은 1,106,504,248바이트다. 전체 파일 수와 파일당 25MiB 제한 검사를 통과했다. 업로드 성공이나 실제 클라우드 요금·접근 제어를 검증했다는 뜻은 아니다.

## 남은 실행 조건

Wrangler 로그인 상태는 아직 연결되지 않은 것으로 확인했다. 실제 계정·허용 이메일 한 주소·관리 자격 증명·같은 Zero Trust 팀의 독립된 다른 계정 증명이 필요하다. 현재 Access adapter는 확인된 preview 비활성 상태와 기본 workers.dev 주소만 허용한다. Free 플랜의 실제 응답 형식과 계정 API 호환성은 인증 후 확인해야 하며, 알 수 없는 상태는 거절한다.

자료가 없는 빈 앱을 먼저 게시하고 Access를 설정한다. 비로그인·다른 계정의 차단과 본인 접근을 실제 본문·해시로 확인한 후에만 실제 자료를 게시한다. 이 작업은 사용자 승인과 실계정 준비 이후 진행한다.

## 알려진 원본 경고

기계학습의 연결 문서 하나가 요청하는 Google Fonts Pretendard 주소는 HTTP 400을 반환한다. 정확한 문서·URL·실패 종류만 실행 시 예외로 기록했다. 원본과 사본에서 같은 텍스트와 폴백 가독성을 확인했으며, 해당 글꼴이 로드됐다고 주장하지 않는다. 미완료 요청·시간 초과·다른 파일 오류는 이 예외로 허용하지 않는다.

전체 브라우저 검사 첫 실행에서는 기존 Firefox 탐색 사례 하나가 멈췄다. 같은 사례를 다섯 번 반복하고 설정을 바꾸지 않은 전체 검사를 다시 실행해 모두 통과했으며, 원인은 확정하지 않았다. Windows의 원자적 보고서 교체 중 확인된 일시적 파일 잠금은 경로 안전성을 매번 재확인하는 제한된 재시도로 처리한다. 지속되는 오류는 실패로 남긴다. 반복 빌드 테스트 한 건은 기존 개별 30초 제한 대신 이미 사용 중인 공통 60초 제한을 적용하며 빌드 횟수와 검증은 유지한다.
