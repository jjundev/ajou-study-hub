## 남은 실행 조건

게시 후 검사 중 연결 HTML 한 개의 GET이 30초 시간 초과로 중단됐다. 로컬 검사 도구의 처리되지 않은 오류가 본인 검사 세션 쿠키를 오류 출력에 포함했다. API 토큰은 출력되지 않았다. 도구에 전체 오류 경계를 추가했고, 해당 검사 세션의 로그아웃 후 이전 쿠키가 로그인 리다이렉트로 차단됨을 확인했다. 이전 세션 파일은 폐기된 상태로 별도 보존했다. 새 본인 세션의 신원 응답에서 서비스 토큰 상태 항목이 생략됨을 확인하고 실제 앱의 OTP 공급자 ID와 신원을 함께 검증하도록 보완했다. 새 세션으로 대표 12개 경로의 원본 바이트·본인 접근·비로그인/다른 계정 미노출 및 검사 전후 정책 일치를 모두 통과했다. 전체 자료의 게시 후 검사나 실제 모바일/PC 사용자 인수를 완료했다고 주장하지 않는다.


2026-10-26 추가 검증: 분리된 두 세션에서 실제 본인·다른 계정의 팀 신원을 확인했다. 본인은 검증용 파일 6개를 원본과 같은 바이트로 받았고, 비로그인 및 다른 계정에는 파일 내용이 노출되지 않았다. 다른 계정은 대상 앱에서 로그인 화면으로 돌아왔으며 최종 403은 확인되지 않았다. Cloudflare 공식 정책 검사 화면과 읽기 API는 대상 앱에 대해 본인 `success`, 다른 계정 `fail`을 반환했고 계정·이메일·앱 ID를 대조했다. 이는 기존 최종 403 조건을 충족한 것으로 처리하지 않는다. 최초 검사에서는 보호 증거를 실패 상태로 유지했고, 사용자 기준 변경 승인 전에는 실제 자료 배포를 보류했다. 사용자가 독립 신원·공식 정책 거부·파일 미노출을 결합하는 기준을 승인했고, 해당 v2 검증기를 실제 계정에서 실행해 보호 증거를 생성했다. 전체 테스트 230개와 타입 검사, 별도 보안 리뷰를 통과했다. 실제 자료 업로드와 게시 후 대표 12개 경로의 자동 검증을 완료했다. 본인 계정의 OTP로 이용할 수 있으며, 자동 갱신 코드 준비 이후의 활성화·실제 인수는 대기 중이다.


독립된 본인·다른 계정의 로컬 검증 세션과 v2 보호 증거를 확보했다. 현재 Access adapter는 preview 비활성과 기본 workers.dev 주소만 허용한다. 실제 API 읽기 호환성은 확인했으며 알 수 없는 상태는 계속 거절한다.

자료 없는 검증용 bootstrap은 게시했다. 다른 계정의 차단과 본인 접근을 독립 인증 세션 및 sentinel 본문·해시로 확인한 후에만 실제 학습 자료를 게시한다. 현재 비로그인 차단 검사와 본인 화면 관찰은 정식 보호 증거를 대체하지 않는다.

## 알려진 원본 경고

기계학습의 연결 문서 하나가 요청하는 Google Fonts Pretendard 주소는 HTTP 400을 반환한다. 정확한 문서·URL·실패 종류만 실행 시 예외로 기록했다. 원본과 사본에서 같은 텍스트와 폴백 가독성을 확인했으며, 해당 글꼴이 로드됐다고 주장하지 않는다. 미완료 요청·시간 초과·다른 파일 오류는 이 예외로 허용하지 않는다.

전체 브라우저 검사 첫 실행에서는 기존 Firefox 탐색 사례 하나가 멈췄다. 같은 사례를 다섯 번 반복하고 설정을 바꾸지 않은 전체 검사를 다시 실행해 모두 통과했으며, 원인은 확정하지 않았다. Windows의 원자적 보고서 교체 중 확인된 일시적 파일 잠금은 경로 안전성을 매번 재확인하는 제한된 재시도로 처리한다. 지속되는 오류는 실패로 남긴다. 반복 빌드 테스트 한 건은 기존 개별 30초 제한 대신 이미 사용 중인 공통 60초 제한을 적용하며 빌드 횟수와 검증은 유지한다.
